# Gentle Hours Counseling

请为我设计并制作一个中文心理咨询师个人网站，重点是呈现咨询师的专业与温度，并让来访者能安心了解服务、查看可预约时间、提交预约意向。

## 视觉风格

请参考我提供的两张图片：

- **整体气质**：像一间安静、自然、讲究材质的茶室或工作室。温和、克制、有呼吸感，避免常见心理服务网站的模板感，也不要做成科技公司或 SaaS 产品页面。
- **颜色**：以暖白、米色、浅沙色为主，搭配少量石墨灰、深棕或低饱和鼠尾草绿。避免鲜艳色、大面积渐变和高饱和紫蓝色。
- **版式**：留白充足，采用清晰的网格和整齐的内容边界。标题醒目但不过分厚重，正文易读；可搭配细线分隔、编号章节、小型标签和简洁的导航栏。
- **图片与纹理**：优先选择自然光、植物、石材、陶器、纸张等安静的生活场景，图片色调柔和统一。可用轻微纸张颗粒或细腻材质感，但不要影响阅读。避免使用明显的医疗、病患或“治愈成功”类图片。
- **动效**：只使用轻微、缓慢的淡入或悬停反馈，不做视差、弹跳或抢眼动画。
- **响应式**：桌面端和手机端都要保持清晰、舒适，导航、按钮和表单在手机上易于操作。

## 页面结构

### 1. 顶部导航

使用简洁的固定或轻量导航，包含：

- 咨询师姓名或个人品牌（使用占位内容）
- 关于我
- 咨询方式
- 适合的议题
- 可预约时间
- 联系方式

导航中的预约入口可以略微突出，但保持克制。

### 2. 首屏介绍

设计一个宽敞、安静的首屏，可采用左右分栏或文字叠加在大幅自然场景图片上的构图。包含：

- 一句简短、有温度的主标题，例如“给自己一点时间，听见内心的声音”
- 一段介绍咨询空间与工作方式的副标题
- 咨询师姓名、身份和咨询方向的占位信息
- “了解咨询方式”和“查看可预约时间”两个入口

文案保持真实、平和，不承诺疗效，不暗示咨询能解决所有问题。

### 3. 关于我

以编辑式图文布局呈现个人介绍，可使用一张自然、可信的职业肖像占位图。内容包括：

- 专业背景与受训经历
- 主要工作取向或咨询方法
- 咨询理念与关系中的工作方式
- 适合接待的年龄或人群

没有提供的姓名、学历、资质、工作年限、机构经历和专业认证都用明确占位符，不得编造。

### 4. 咨询方式

用清晰的小节或编号卡片说明：

- 线上或线下咨询方式
- 单次时长
- 咨询频率与初次沟通流程
- 费用与取消、改期规则

具体费用、地址、时长等未知信息都以“待补充”或可替换占位内容显示。

### 5. 适合讨论的议题

用温和、非诊断式的语言介绍目前可以讨论的需求，例如情绪压力、人际关系、自我探索、亲密关系或生活转变。具体范围由咨询师资料决定，未确认的内容先用占位符。

同时简要说明不适合本服务或需要转介的情况。不要给访客贴标签，也不要在网站上做诊断。

### 6. 可预约时间

设计一个易读的周历或时段列表，清楚标明日期、时间和时区，并提供选择时段的交互。

当前未接入真实预约系统时：

- 明确提示预约时段为示例或需人工确认
- 不要显示虚假的实时空位
- 用户选择时间后，仅提交“预约意向”，不要显示预约已确认
- 用占位方式呈现可编辑的日期和时段

### 7. 预约表单与流程

表单只收集预约所需的最少信息，例如称呼、联系方式、希望的咨询方式、意向时段，以及可选的简短需求说明。说明提交后的处理步骤和预计回复时间，未知内容使用占位符。

在表单旁或下方添加简洁的隐私说明：信息仅用于预约沟通，并提示不要填写过多敏感个人信息。不要收集身份证号、详细病史等与预约无关的信息。

### 8. 页脚与紧急支持说明

页脚包含联系方式、社交媒体或公众号占位入口、隐私说明和版权信息。另以清楚但不吓人的文字说明：本网站不提供紧急危机支持；如遇即时危险，请联系当地紧急服务或专业危机支持渠道。

## 文案与实现要求

- 全站使用英语，语气温和、清晰、尊重来访者。
- 不编造我的个人资料、资历、服务承诺、费用、地址、时间或客户评价。
- 未提供的信息以醒目的可替换占位内容标明，便于我后续修改。
- 不使用“保证改善”“快速治愈”等承诺性表达，不伪造客户评价、预约数量或资质标识。
- 页面内容层次清晰，按钮文案准确，表单字段带有清楚的标签和提交反馈。
- 最终效果应像一个有编辑感、材料感和安静气质的个人工作室网站：简洁、可信、温暖，避免装饰过度。
